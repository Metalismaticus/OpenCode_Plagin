## Порядок

Работать строго по инструкции команды `/studio/add` — координатор называет путь к ней
в сообщении. Где она велит спросить владельца окном — вместо окна блок
«Вопрос владельцу» в итоге. Дополнительно прочитать `AGENTS.md`,
`docs/BLOCKED.md` (что именно ждали) и `docs/orders/<вид>.md` каждого
пришедшего вида (раздел «Приёмка»).

Коротко:

1. `git status` — что появилось в папках назначения из паспортов
   `docs/orders/*.md` и по точным путям долгов `docs/BLOCKED.md` (кадр-цель
   — `docs/refs/<тема>/target-*`);
2. узнать файлы по долгам в `docs/BLOCKED.md` и по заказам в `docs/prompts/`;
3. **до того как открыть файл** — `python -X utf8 tools/asset_check.py <файл>
   …` с аргументами из заказа (`/studio/add`, раздел 3); модель `.glb`/`.gltf` —
   `python -X utf8 tools/model_check.py <файл> …` (треугольники против
   бюджета, габариты в метрах, опорная точка, текстуры внутри; аргументы —
   из заказа `model3d`, коды те же), не «не умею» `asset_check.py`; нет
   скрипта в проекте — тот же файл из папки шаблонов плагина; в контекст —
   только последняя строка. Код 1 — брак: файл не принимать и не открывать,
   убрать из проекта и написать строку «перезаказать: `<файл>` — <почему>»;
   «поправить: …» — поправить и проверить снова; код 2 и «послушать» — как
   там же (послушать — блок «Вопрос владельцу»). Код 0 — дальше по разделу
   «Приёмка» его вида (у модели — снимок на стенде рядом с капсулой, стоит на
   земле, смотрит «вперёд»);
4. выполнить «после правки ресурсов» из `docs/TESTING.md`;
5. однозначно узнанные файлы — отдельным импортным коммитом, файлы поимённо
   (принятого нет — коммит о браке), пометка `Assets:` / `Ассеты:` — `/studio/add`,
   раздел 5; отправить, если в `AGENTS.md` контрольные коммиты отправляются;
6. строки для очереди и долгов — в `docs/BATCH.md`, раздел «Пришло — внести в
   очередь»; права каждого файла — в его строку `docs/orders/ledger.md`
   (`/studio/add`, раздел 4; у моделей — источник и лицензия: Poly Pizza CC-BY с
   автором, Poly Haven CC0, Meshy и Tripo — по тарифу из заказа, бесплатный
   — с атрибуцией и без продажи, пока тариф не платный). Сами `ROADMAP.md` и
   `BLOCKED.md` не править: их ведёт чат замысла.
