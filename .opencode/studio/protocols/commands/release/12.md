## 8. Запись и отчёт

- `docs/DECISIONS.md`, `## Выпуски` (нет — завести в конце): `- <дата>:
  v<версия> на <хеш сборки> — сборка <пресеты>; проверка сборки: <итог |
  руками владельца>; полная <зелёных>/<провалов>; itch <канал>: выложено |
  не выкладывали; Steam бета <ветка>: BuildID … | не выкладывали;
  ИИ-контент: да | нет; заметки docs/releases/<версия>.md`. Продолжение —
  дополнить строку этой версии.
- README — блоки `release`, `features`, `pitch`, `run`, About в «Git»
  `AGENTS.md` — пересобрать по `.opencode/studio/reference/COMMITS.md`.
- Документальный коммит `Release:` / `Выпуск:` — версия и главное для игрока
  («Release: Ship 1.2.0 with night raids and a world map» / «Выпуск: 1.2.0 —
  ночные набеги и карта мира»), файлы поимённо: заметки, `CREDITS.md`,
  `docs/DECISIONS.md`, README, если меняли — `AGENTS.md`, `docs/TESTING.md`
  («сборка», «Выпуск», «Окружение») и `.gitignore`; отправить вместе с тегом
  (`git push`, `git push origin v<версия>`), если в `AGENTS.md` коммиты
  отправляются.
- Отчёт словами продукта: версия и что в ней для игрока (2–3 строки); где
  лежит сборка; чем проверена и чего не проверено; куда выложено и где
  посмотреть (страница itch.io; в Steam — «Свойства → Бета-версии»); что
  сделать руками: вставить раскрытие ИИ в Steamworks, перевести ветку по
  умолчанию, когда бета проверена; About изменился и есть удалённый на
  GitHub — две строки по «About» `COMMITS.md`. Последняя строка — один следующий шаг.
