## 2. Сборка

- Команда — строка «сборка» в «Командах проверки» `docs/TESTING.md`,
  вердикт — по «Как читать вердикт», с пределом времени из таблицы.
- Папка — из «Выпуск», подпапка `<версия>` — новая и пустая: butler выложит
  всё, что в ней лежит. Вне проекта или в `.gitignore` (нет — дописать
  строку, коммит п. 8).
- Godot: движок — консольный (`…_console.exe`) из «Окружения»; из папки
  проекта `"<движок>" --headless --export-release "<пресет>" <путь>`, папку
  создать заранее. Шаблоны экспорта `%APPDATA%\Godot\export_templates\<версия>`
  — ровно под версию движка из «Окружения» (`4.3.stable` для
  `4.3.stable.official…`). Нет или не та — окно «Шаблонов экспорта Godot
  <версия> нет — без них игру не собрать. Как поставим?» — `Поставлю сам в
  редакторе (Recommended)` (Editor → Manage Export Templates → Download) /
  `Отложить выпуск`; затем строка в «Окружение».
- Строка «сборка» — «нет» или пуста: у Godot — собрать её по образцу выше и
  после удачной сборки записать в таблицу; пресета нет или стек другой —
  стоп: пункт «сборка для <платформы>» — через `/studio/idea`.
- Игра сама показывает номер (Godot — непустой `application/config/version`
  в `project.godot`) — окно п. 4 до сборки, номер — туда, коммит `Release:`
  / `Выпуск:` («Release: Show version 1.2.0 in the game» / «Выпуск: номер
  версии 1.2.0 в игре»; полную не повторять — сборку проверит п. 3).
- Удача — зелёный вердикт **и** файл игры в папке не пустой. HEAD — «хеш
  сборки».
