## 4. Версия и тег

- Прошлый тег — первая строка `git tag --list "v*" --sort=-v:refname`; нет —
  первый выпуск, `0.1.0`.
- С прошлого тега: строки, добавленные в «Сделано» `docs/ROADMAP.md` (`git
  diff v<прошлая>..HEAD -- docs/ROADMAP.md`), и коммиты пунктов — обеими
  пометками (`git log v<прошлая>..HEAD -E --grep "^(Пункт|Item) [0-9]+:"`,
  `.opencode/studio/reference/COMMITS.md`); уборки кода (строки «— для игрока без
  изменений», коммиты `(no change for players)`) — не в счёт. По semver:
  только исправления — `x.y.Z+1`; новое для игрока — `x.Y+1.0`; большое
  (формат сохранения, переделка ядра, пункты с `Необратимо`) — `X+1.0.0`.
- Окно «Какая версия? Прошлая — v<прошлая>; с тех пор <N исправлений, M
  нового>» — `<номер> — исправления` / `<номер> — новое` / `<номер> —
  большое`, рекомендуемый первым с `(Recommended)` и причиной. Номер в
  аргументе — без окна.
- `git tag v<версия>` на хеше сборки. Такой тег уже есть — п. 1, первая
  строка.
