
Что просит владелец: **$ARGUMENTS**

(Если строка выше пуста или осталась без подстановки — взять из сообщения
владельца.)

Вопросы владельцу — окнами по `.opencode/studio/reference/ASKING.md`.

Настройки живут в первой строке раздела «Параллельная работа»
`docs/TESTING.md`:

```
**Состояние: проверено · пишут: 3 · тяжёлых проверок: 1**
```

- **пишут** — сколько пунктов партии пишется одновременно, каждый в своей копии
  проекта; при них идут только короткие проверки: пункта, группа, быстрая.
- **тяжёлых проверок** — сколько полных и долгих прогонов идёт одновременно.
  Обычно 1: в `/studio/start all` полная идёт одна, в конце партии.

Это **потолки**, а не план: сколько пунктов реально пойдут вместе, решает
разведчик `scout` по каждой партии; независимых нет — всё по одному при любом
`пишут`. Старая строка `предел: N` читается как `пишут: N · тяжёлых проверок:
1`; при первой записи заменить её новой.
