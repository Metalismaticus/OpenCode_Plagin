# Look/feel variants and choice

Read `.opencode/studio/protocols/commands/start/06.md`.
This chapter preserves the original branch, including failures and rollback.
Create one task id per stand/base/choice/embedding step. Set owner_result:false
for intermediate stand/base/choice cards; embedding is owner_result:true.
Earlier stages are checkpoints; only the final player result goes to owner acceptance.
Placeholder-first: the stand rises on grey forms with the real light, haze
and tone; the global look is judged and checkpointed on those placeholders
BEFORE any art is generated or ordered. Art then lands piece by piece
(backdrop → masses → hero), each piece re-judged against the passport.
Baked glow, shadows, particles or text inside a picture are a red review
finding: the engine draws them, pictures only carry flat art.
For acceptance read .opencode/studio/protocols/commands/done/01.md and 02.md before showing frames.
Task transitions use studio_workflow; do not replace them with BATCH labels.
