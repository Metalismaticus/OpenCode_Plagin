# Godot shader work

Load studio-godot. Confirm Forward+, Mobile or Compatibility from project data,
the material type, render modes, coordinate spaces, depth conventions and
resource ownership. Do not copy Godot 3 syntax into Godot 4 code.
Use the reference passport's chosen technique, lighting and canonical frames.
Compile/import first, then capture in the owner's actual scene; a screenshot
on a flat isolated testbed is not proof of the world result. Look at silhouette,
edges, transparency, depth interaction, temporal stability and low/high presets.
Record unavailable vision honestly. Use the comparison sheet/sanity tools.
Expensive depth reads, extra passes or cameras need the task's performance
budget; many chunk-loaded effects need lifecycle and cost checks. Do not tune
only constants for two rounds while the same technique defect remains.
