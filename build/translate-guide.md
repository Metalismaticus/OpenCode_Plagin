# Правила перевода протоколов студии на английский

Документ для переводчиков-агентов. Переводим ПРОТОКОЛ (то, что читает
модель) с русского на английский. Смыслы и дисциплина не меняются:
критерии не ослабляются ни на йоту — перевод точный, консервативный,
телеграфный стиль сохраняется.

## Файлы, которые переводим (только они)

- `.opencode/agents/*.md` — тела (после frontmatter)
- `.opencode/commands/studio/*.md` — тела
- `.opencode/skills/*/SKILL.md` — тела + frontmatter (name, description)
- `.opencode/studio/setup-steps/*.md` — целиком
- `.opencode/studio/reference/ASKING.md`, `COMMITS.md`, `LOOK_TECHNIQUES.md`

## Файлы, которые НЕ трогаем

- frontmatter агентов и команд (description — владелец видит в пикерах) —
  русский остаётся; skills frontmatter — переводим (объявляется модели
  на каждом шаге)
- `.opencode/studio/templates/**` — документы проекта (читает владелец)
- `.opencode/studio/hooks/*.py`, `env_check.ps1` — сообщения владельцу
- `README.md`, `install.ps1`, `build/*`, `.opencode/plugins/studio.ts`

## Что остаётся РУССКИМ внутри английского текста — дословно, никогда не переводится

1. **Форматы артефактов** — строки-ярлыки итогов, вопросов, пометок
   (они идут в документы и чат, владелец их читает):
   `Пункт N: готово | не удалось | ждёт`, `Файлы:`, `Красное без
   исправления:`, `Зелёное:`, `Проверки:`, `Как увидеть:`, `Кадр:`,
   `Вижу:`, `Против образца:`, `Способ:`, `Лист:`, `Пресет:`,
   `Решено за вас:`, `Ловушка:`, `Коммит:`, `В документы при /studio/done:`,
   `Замечено вне пункта:`, `Вопрос владельцу:`, `Пока нет ответа:`,
   `Бриф:`, `оси выбора:`, `Смотреть самому`, `было / стало / образец`,
   `в работе`, `готов к проверке`, `ждёт очереди`, `ждёт выбора`,
   `ждёт: …`, `Уборка:`, `уборка: …`, `Решил сам:`, `Принято по умолчанию`,

   «Метки пунктов очереди», «Правила процесса», «Как спрашивать
   владельца», «Какой документ когда», «Окружение», «Запуск и проверка»,
   «Архитектура», «Где что», «Копии», «Службы», «Слова владельца»,
   «Готово, когда», «Не входит», «Дальше», «Где», «Нельзя ломать»,
   «Ловушки стека», «Стенд», «Сценарии игрока», «Как добавить проверку»,
   «Правила каркаса», «Команды проверки», «Как открывается окно»,
   «Общие узлы», «Набор копий», «Параллельная работа», «Замеры»,
   «Как мерить», «Бюджет производительности», «Здоровье кода»,
   «Нестабильные проверки», «Принято без полной проверки», «Этапы»,
   «Покрытие замысла», «Очередь», «Сделано», «Потом», «Не делаем»,
   «Что работает», «Одной строкой», «Ядро», «Цель и провал»,
   «Чего не делаем», «Старт», «Приёмка», «Разрыв», «Журнал».
4. **Поля паспорта и паспортные значения**: «У нас:», «Как сделано у
   образца», «Главное впечатление», «Важно владельцу: да», «Кадры»,
   «Образец для листа», «Чем делаем: код | файл», «Вид работы: вид |

5. **Пары пометок коммитов**: `Item N:` / `Пункт N:`, `Batch:` / `Партия:`,
   `Accept:` / `Приёмка:` и остальные пары из COMMITS.md — как есть.
6. Пути, имена файлов, команд (`/studio/…`), скриптов и агентов — как есть.

## Стиль и структура

- Заголовки переводим: `## 3а. Волна` → `## 3a. Wave`; все ссылки
  «раздел 3б» → "section 3b", «п. 5» → "step 5" / "p. 5".
- Структуру markdown сохраняем: списки, вложенность, код-блоки
  (код-блоки с русскими строками форматов — дословно).
- Телеграфный стиль сохраняем: без «please», без воды; императив.
- Правило не ослаблено, если перевод длиннее оригинала — пусть.
- Сомневаешься — переводи консервативнее (ближе к дословному).

## Глоссарий (единый для всех файлов)

партия → batch · пункт → item · очередь → queue · этап → stage ·
круг → round · волна → wave · слот → slot · копия проекта → worktree
copy · слияние → merge · контрольный коммит → checkpoint commit ·
откат → revert · исполнитель → executor · проверяющий → reviewer ·
координатор → coordinator · чат замысла → concept chat · чат
разработки → dev chat · владелец → owner · бриф → brief · стенд →
stand · основа → base · выбор → choice · встроить → embed · вариант →
variant · приём → technique · лист сравнения → comparison sheet ·
снимок → screenshot · кадр → frame · паспорт → passport · образец →
reference (игра-образец → reference game) · разбор образца → reference
analysis · красное доказательство → red proof (проверка до правки →
failing test first) · сценарий игрока → player scenario · полигон →
testbed · полная проверка → full run · быстрая проверка → quick run ·
здоровье кода → code health · замер → measurement · зонд → probe ·
находка → finding · уборка → cleanup · замечание → review note · окно
(вопроса) → the `question` dialog · приёмка → acceptance · отказ →
rejection · лестница качества → quality ladder · пресет → preset ·
приёмка парии → batch acceptance · «было / стало / образец» → keep
Russian (screen labels) · стенд вида/ощущения → the look stand / the
feel stand (в коммитах: `Add the look|feel stand`) · возврат с выбора →
rollback from a choice · общие узлы → shared hubs · храповик →
ratchet · зона видимости — n/a · «Решено за вас» → the «Решено за
вас» label (keep Russian) · дословно → verbatim · окно → dialog ·
вопрос списком → the same question as a numbered list.

## Самопроверка после каждого файла

Оставшаяся кириллица допускается ТОЛЬКО из списка выше (ярлыки,
метки, названия разделов в кавычках, поля паспортов, пары пометок).
Прочая кириллица — переведи. Каждое правило оригинала должно
присутствовать: пройди файл глазами построчно против оригинала
(оригинал той же версии лежит в ../CLAUDE_Game/plugins/studio —
сверяй при сомнении).
